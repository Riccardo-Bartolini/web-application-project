# Eterna Eleganza — University E-commerce Project

An e-commerce web application for watches developed by a two-student team for the Web Technologies course at the University of Bologna (2024/2025). The project includes a customer-facing catalogue and checkout flow, alongside pages for vendors to manage products and orders.

## Features

- Product catalogue and individual product pages
- Customer registration, login and private area
- Shopping and checkout flow
- Vendor product management and order views

## Technologies and structure

The application uses PHP, MySQL, Twig templates, HTML, CSS and JavaScript.

- `Ecommerce/` — PHP application, controllers, models, views and database configuration
- `frontend/` — HTML, CSS, JavaScript and images
- `Mockup/` — interface mockups
- `report.pdf` — project report
- `DiagrammaWorkflow.pdf` — workflow diagram

## Running the project

This repository is an archive of the university submission. It requires PHP, Composer and a local MySQL database. The database schema is in `Ecommerce/config/table_creation.SQL`.

The current database configuration must be replaced with local, private credentials before running the application. A complete, verified one-command setup is not yet provided.
